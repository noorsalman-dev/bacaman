#  Infinity Bacaman

A small arcade-style web game inspired by classic pellet-collecting games, but with potatoes.

Play as Bacaman, collect pellets, avoid enemy potatoes, and survive for as long as possible while increasing your score. As the game progresses, more enemies will appear and the challenge becomes harder.

##  Features

- Smooth keyboard movement
- Infinite-style play area
- Collectible pellets
- Enemy potato 
- Score tracking
- Progressive difficulty


## How to Play


### Objective

1. Collect as many pellets as possible.
2. Avoid enemy potatoes.
3. Increase your score.
4. Survive as long as you can.
